A Jupyter notebook template for modeling and controlling a UR10 robotic manipulator using ROS (Noetic) and Python. It walks through computing inverse kinematics with the Robotics Toolbox, connecting to a ROS master, and commanding joint trajectories via both the topic interface and the action server/client interface. Includes point-to-point and multi-waypoint motion examples, joint state/velocity monitoring, and trajectory plotting, with simulation in Gazebo/RViz.

**Requirements**: ROS Noetic, roboticstoolbox-python, spatialmath-python, a UR10 URDF, and the ur_launch package.
